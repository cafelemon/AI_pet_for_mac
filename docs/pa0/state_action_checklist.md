# State Action Checklist

| State | PA0 Target | Priority |
|---|---|---|
| idle | Natural standing pose with optional small action frame. | P0 |
| coding | Character at a small computer, focused on work. | P0 |
| thinking | Character thinking with visible question mark cue. | P0 |
| success | Happy jump or celebration pose with small fireworks. | P0 |
| error | Low-energy sitting pose with small rain cloud. | P0 |
| reminder | One hand on waist, one hand pointing to reminder bubble. | P1 |
| sleep | Sleeping in a small cup bed with Zzz effect. | P1 |
| idle_reading | Idle small action: seated reading. | P1 |
| idle_yawn | Idle small action: yawning. | P1 |
| idle_hair | Idle small action: adjusting hair. | P1 |

`waiting_auth` is reserved for the later Codex integration phase and is not a PA0 required keyframe.
