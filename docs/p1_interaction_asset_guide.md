# P1 Interaction Asset Guide

P1-A 先补 6 个用户交互动作用的源视频。请保持角色服装、比例、镜头高度和当前动作资产一致，白底或干净浅色背景，固定镜头，无字幕、水印、边框和多余道具；每段建议 2-3 秒，动作首尾尽量接近自然站姿，方便后续转透明 WebM。

## Motion Notes

- `mouse_hover_look`: 鼠标靠近时抬头或转头看向鼠标，幅度轻，像注意到用户。
- `mouse_leave_back`: 视线从鼠标方向自然收回，回到普通站姿。
- `click_head_happy`: 被点头部后开心眨眼、微笑或轻轻点头，反馈要短。
- `click_body_confused`: 被点身体后轻微困惑、歪头或小退半步，不要太夸张。
- `drag_start_lift`: 拖拽开始时进入被轻轻提起或准备被拖动的姿态。
- `drag_end_dizzy`: 拖拽结束后落地，短暂晕乎或摇晃，然后站稳。
