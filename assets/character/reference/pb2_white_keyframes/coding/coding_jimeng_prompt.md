# coding

## 动作规格

- 播放类型：`loop`
- 建议时长：4-5 秒
- 动作：小电脑前敲代码
- 源视频放置：`assets/states/coding/source/coding_jimeng.mp4`
- 最终 WebM：`assets/webm/coding/coding_loop.webm`

## 即梦提示词

使用提供的纯白背景关键帧作为角色一致性参考，生成 3-5 秒短视频。
画面要求：9:16 竖屏，纯白背景，固定镜头，完整性优先于透明效果优化。人物、电脑、桌子、椅子在每一帧都必须完整可见，不允许裁切头顶、鞋子、椅面、椅腿、桌面、桌腿或电脑边缘；无阴影、无地面、无水印、无字幕。
角色要求：保持参考图中的同一个真人桌宠角色、服装、发型、面部一致，不要改变年龄、体型、五官或服饰。
道具要求：桌子、椅子、电脑必须始终存在且结构完整。桌椅不要使用纯白色，改为浅暖灰、米白偏灰、浅木色这类与纯白背景可区分的浅色；电脑保持完整轮廓，屏幕不要出现文字或界面。
动作要求：动作自然轻微，适合作为透明桌宠循环或短动作，动作幅度不要过大，手指轻快敲击键盘即可，不要大幅摆臂，不要让桌椅或电脑移出画面。
输出要求：尽量导出 MP4，文件名按 <state>_jimeng.mp4 命名。

具体动作：让角色坐在小电脑前敲代码，眼神专注，人物姿态稳定，桌椅电脑完整且轮廓清晰，优先保证成片在纯白背景抠像后仍能保住完整桌椅结构。
